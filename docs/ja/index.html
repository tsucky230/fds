⌨️ FDS

キーボード操作を中心にした、軽量・高速なTUIファイルマネージャーです。
「考えるより先に操作できる軽快さ」を、現代のターミナル環境向けに作り直しています。

⌨️ キーボード中心

すべての操作がキーボードで完結。ファンクションキーが使えない環境にも対応。

🚀 軽量・高速

最小限のリソース使用。どのターミナルでも即座に反応します。

🌍 SSH・Headless対応

リモートサーバーやターミナル環境でもそのまま動きます。

📦 アーカイブ機能

ZIP、tar、tar.gz、tgzの閲覧・作成・展開が組み込まれています。

👁️ ユニバーサルビューア

テキスト、Markdown、16進、画像を自動判定で表示。

🔒 信頼性

安全なファイル操作。エラーハンドリングも充実。
