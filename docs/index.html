⌨️ FDS

A lightweight, fast TUI file manager focused on keyboard operation. Recreates the "responsiveness that lets you act before you think" for modern terminals.

🎯 Keyboard-First

All operations via keyboard. Alternative keys for all environments.

🚀 Fast & Light

Minimal resource usage. Instant response on any terminal.

🌍 SSH & Headless

Works on remote servers and terminal-only environments.

📦 Archives

ZIP, tar, tar.gz, tgz browsing and extraction built-in.

👁️ Universal Viewer

Text, Markdown, hex, and images with auto-detected encoding.

🔒 Reliable

Safe file operations with proper error handling.
